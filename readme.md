# NOVA — Team Productivity Platform

> Plan. Collaborate. Deliver.

NOVA is a full-stack project management platform designed
for teams to manage projects, tasks, members and productivity.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

### Development
- Git
- GitHub
- Postman

## Project Structure

- client → Frontend
- server → Backend
